CSV파일 구조

anchor_id : 마커 이름

object_name : 마커에 띄우진 오브젝트 이름

pos_x,pos_y,pos_z : 오브젝트 x,y,z좌표

rot_x,rot_y,rot_z : 오브젝트 회전값

scale_x,scale_y,scale_z : 오브젝트 크기

예시:
marker1,toy,32,21,11,33,22,22,1,1,1
marker1,train,32,11,12,22,22,22,1,1,1
